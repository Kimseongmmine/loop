# LOOP

- **무엇**: 전날 밤에 "내일 오전에 할 단 하나"를 확정해, 아침엔 선택할 것이 없게 만드는 개인용 단일 페이지 PWA. 하루 항목은 오직 하나.
- **왜**: 아침의 "뭘 할지 고르는 선택"이 실패 지점이라, 선택을 전날 밤으로 옮기고 아침엔 정해진 하나만 실행한다.
- **스택**: 바닐라 JS + HTML + CSS. 빌드 도구·프레임워크·의존성 0. 저장은 localStorage만. Vercel 정적 배포.
- **실행법**: 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속. 배포는 폴더째 Vercel에 올리면 끝.
- **한계**: 기기·브라우저 로컬 저장(localStorage)만 사용 → 동기화·백업·계정 없음. 알림 없음(스스로 연다). 밤 21:00~03:59 / 아침 04:00~20:59 시각대로만 화면이 갈린다.
