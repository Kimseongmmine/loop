# LOOP

- **무엇**: 내 상황(목표·자유메모)을 적어두고 "계획 생성"을 누르면 AI가 하루(9~24시) 시간표를 짜주는 개인 대시보드. 목표별 진행도·접속 스트릭 표시. 밤에 누르면 내일 것, 낮에 누르면 오늘 것.
- **왜**: 매일 "뭘 할지" 정하는 것 자체가 실패 지점이라, 그 결정을 AI에게 넘긴다. 핵심 3개만 하면 오늘 성공(무너짐 방지).
- **스택**: 바닐라 JS + HTML + CSS. 빌드도구·프레임워크·의존성 0. 저장은 localStorage만. AI는 무료 모델(Gemini 우선, 없으면 OpenRouter). 키는 브라우저에만 저장. GitHub Pages 정적 배포.
- **실행법**: 이 폴더에서 `python -m http.server 8000` → `http://localhost:8000`. 설정에서 목표 추가 → "🔑 Gemini 키 입력"(추천) 또는 OpenRouter 키 입력(선택). 배포는 `git push` → https://kimseongmmine.github.io/loop/ 자동 갱신.
- **한계**: 기기 로컬 저장만. 기기 간 자동 동기화 없음 — 설정에서 JSON으로 직접 내보내고 가져온다. 무료 AI 모델은 가끔 실패 → 자동으로 고정 템플릿 시간표로 폴백(앱은 안 깨짐). 강제성은 접속 스트릭뿐.
